# 구현·검증 상태 — 2026-11-05

전체 게임은 미완성이다. 아래 기능을 전체 완성으로 해석하지 않는다.
최신 사용자 지시: 23개 탭과 모든 요구사항을 구현하고 검증한 뒤 배포한다.
부분 뉴스 배포는 중단했다. 운영 서비스와 운영 DB는 이번 작업에서 변경하지 않았다.

## 이번 로컬 구현

- BO3/BO5 승리 조건, 세트 사이 60초, 점수/세트/형식 저장 및 복원.
- 대회·단계별 규칙 API와 두 앱의 운영자 편집 및 예약 규칙 선택.
- 예약 시 형식을 고정하므로 이후 규칙 수정으로 이미 예약된 경기가 바뀌지 않음.
- 공식 출처가 확인된 First Stand 2026 BO5 초기 규칙. 나머지 대회 전체 규칙은 미완성.
  출처: https://lolesports.com/en-US/news/season-start-2026-lol-esports
- 뉴스 기본/리그/팔로우 필터, 두 앱 팔로우 저장·해제, 신규 커리어 부임 가상 기사.
- 서버 인물 검색, 최대 150명 페이지, 본명 우선, ID 기반 조회, 구단별 등록 인물 조회.
- 운영자 게임용 6개 능력치·2026 폼 평가 저장. 원본 자료·출처는 유지.
- 프로필 진입 연결, 인물 팔로우, 영입 검토 명단 추가·삭제.
- 부임·주차 진행 우편 생성, 개인별 읽음 보존.
- 새 온라인 커리어 후보 50명(포지션별 10명), 코치 10명 저장.
- 포지션별 1명, 선수 5명, 코치 최대 3명 선택·해제·확정.
- 생성 본명·닉네임 전역 중복 검사, 알려진 실존/은퇴 닉네임 예약.
- 초기 선수단 확정 전 턴 진행 방지. 과거 커리어는 모집 시작 기능으로 전환 가능.
- 확정된 가상 선수의 교전 능력은 스킬샷 조준, 시야 능력은 와드 간격에 연결.
  챔피언 기본 피해량은 변경하지 않음. 선수 성향은 고유 ID로 일관되게 유지.
- 리플레이 메타데이터에 실제 선발 인물 ID·본명 추가(관전 HUD 표시는 미완성).

## 검증

- 서버 단위 테스트 7개: BO3/BO5 모든 점수 경로, 5세트 복원,
  대회 규칙 분리, ID 동명이인 분리, 검색/페이지, 초기 후보/선발 제한, 선수-엔진 연결.
- HTTP 통합 테스트: 뉴스/팔로우/권한/커리어/선발/설정/예약/시리즈/턴 중복/
  규칙 스냅샷/평가/우편 읽음/영입 명단.
- 기존 매치엔진 테스트 20개 통과(조준 정확도 변경 후 실행).
- Windows Release 빌드, Android APK 컴파일/디버그 서명 검사.
- Windows smoke는 오프라인 화면·한글·저장·페이지·프로필 범위를 검증.
  새 온라인 화면의 실제 조작 검증과 Android 기기 실행 검증은 별도 미완료.

## 배포 상태와 주의점

- GCP game-server의 rift-manager/rift-match-worker는 기존 단판 배포본으로 active 확인.
- 기존 배포본 server.py를 deployment-review/server.before.py로 읽어 비교했다.
- 뉴스 전용 후보 server.news.py/news.py를 VM 사용자 홈에 준비했으나 사용자 후속 지시로 설치하지 않았다.
- deployment-review/server.news.py는 현재 로컬 전체 구현을 포함하지 않는 과거 비교 후보다. 배포 금지.
- EXE/APK는 테스트 빌드다. 운영 서버가 새 API를 지원하지 않으므로 완성본으로 배포하지 않는다.
- 실제 서버 배포 시 catalog/recruitment 등 새 모듈과 assets/people.json,
  엔진 코드·리플레이 모듈을 함께 검증하고 DB 백업/마이그레이션/롤백이 필요하다.
- 전체 챔피언 고유 스킬, 대회별 피어리스/5밴 밴픽, 피드백 반응,
  방송형 관전 HUD와 60FPS 실측, 실제 리그 및 스폰서, 멀티유저 초대,
  실제 업데이트 배포·서명 체계는 미완료다.
