# R/M 구현 기준

사용자 지정 게임 규칙이다. 현실 대회 규정과 구분한다.
메뉴가 보이는 것만으로 기능 완료로 간주하지 않는다.
완료는 저장과 복원, 정상 진입, 조건별 처리, 결과 반영을 검증했을 때만 기록한다.

## 경기

- 미니언이 적절한 시간 안에 처치되어야 한다.
- 포탑 압박에는 공격적 대응과 팀 단위 수비가 가능해야 한다.
- 불리한 팀은 위험한 단독 운영을 줄이고 집결한다.
- 5대5 교전이 운영과 오브젝트 공방에서 발생해야 한다.
- 넥서스와 포탑이 미니언에 의해 반복적으로 무방비 파괴되는 원인을 해결한다.
- 모든 챔피언의 개별 스킬과 아이템, 스펠, 룬을 구현하고 검증한다.
- 주차 진행과 일정 도달 전에는 경기 계산과 재생을 시작하지 않는다.
- 유저 감독의 경기는 하이라이트 관전, 다른 팀 경기는 비관전 자동 계산한다.
- 경기 결과는 한 번만 확정하며 재시도와 동시 처리로 중복 반영되지 않아야 한다.

## 구단 화면

대시보드, 뉴스 사이트, 우편함, 전술, 훈련, 스탭, 1군,
2군/3군(유소년), 달력, 선수간 관계, 의료 센터,
선수 데이터베이스(페이지당 최대 150명), 전세계 이적 활동,
영입 명단, 영입 예산, 스탭 검색, 스탭 이적 활동,
재정, 대회(순위), 데이터 허브(개인 순위/승률/챔피언 티어),
구단 비전, 내 프로필, 운영자.

뉴스는 한국 매체/인벤/Sheep Esports/ESPN 등 실제 출처와 링크,
게시 시점 및 수집 시점을 구분한다. 생성 기사를 실제 보도로 표시하지 않는다.

전술은 개인 지시, 팀 운영, 한타 구도를 구분해 경기 AI에 반영한다.
관계, 에이전트 협상, 다수 대화 선택지, 선수 갈등 중재,
훈련, 의료, 스탭 계약, 감독 계약과 능력치를 저장하고 결과에 반영한다.

## 시작과 인물

- 새 구단 창단 또는 실제 구단 감독 부임.
- 새 구단은 LCK CL에서 출발.
- 선수 50명 후보, 포지션별 10명에서 1명씩 5명 선발.
- 코치 10명 후보에서 최대 3명. 저장 및 이적 시에도 제한 검사.
- 생성 인물 본명/닉네임은 구단 간 중복 없이, 숫자만 붙이는 방식 금지.
- 생성 닉네임에 유명 현역/은퇴 선수 이름을 재활용하지 않는다.
- 실존 인물은 원본 인물 ID, 등록 역할, 팀, 계약 출처, 자료 기준일 보존.
- 미확인 계약은 게임용 1년. 확인 계약 날짜와 추정 계약을 구분.
- 비공개 연봉은 능력치에 따른 게임용 추정치.
- 실제 2026 폼과 챔피언 숙련도는 경기 기록과 평가 기준을 보존.
- 선수 상세는 본명/닉네임/계약/연봉/성격/챔프폭과 6각형 능력치.
- 로고 JPG/JPEG/PNG/SVG. 실제 팀 로고/사진은 출처와 인물 연결 검증.

## 104주 시즌과 턴

사용자 후속 지시에 따라 104주/턴 시즌을 사용한다.
지역별 실제 스플릿/컵/PO/국제대회/하부리그 일정 조사 후 104주 배치를 검토한다.
원본 현지 날짜와 게임 주차를 구분하고, 날짜 변환 및 국제대회 참가 팀의 국내 일정 충돌을 검사한다.
스토브 중 FA와 감독 교체도 가능하나 극히 드물게 발생.
온라인 유저의 엄격한 과반수 동의 또는 운영자 진행.
동일 턴 중복 진행, 탈퇴/접속 상태에 따른 투표 분모, 결과 중복 반영을 명시적으로 처리.
서버가 구단/선수/투표/경기/일정의 기준 상태를 관리한다.
Windows EXE/Android APK는 같은 서버와 계정을 이용하며 기기별 입력/화면/성능을 검증.

## 구단주/스폰서

구단주 등장 전 지역 모집/지인 소개로 선수 영입.
1부 승격 뒤 구단주 등장 가능성을 크게 높인다.
덜 알려진 국내 기업 50곳과 유명 기업 50곳을 실제 기업 데이터로 구성.
기존 실제 스폰서 및 추가 실제 기업 유치.
스폰서는 최대 5곳, 유니폼 스폰서는 별도 취급.
실제 후원 관계와 게임 속 가상 유치 계약을 구분.

## 리그 구조

### 한국
LCK/LCK CL 승강전. CL 1위 대 LCK 10위, CL 2위 대 LCK 9위.
CL 우승만으로 자동 승격하지 않는다.
CL은 허용된 프랜차이즈 2군과 세미프로 참가.
구단주 있는 승격 기업 구단의 사무국 심사를 통해 프로 지위와
2군 참가 자격을 부여할 수 있고 팀 수 증가 시 일정 재편성.
LCK AS는 3군 전용, 승강전 없음.

### 중국
LPL/LDL. LDL은 2군, 세미프로 없음. 승강전 없음.

### 북미/라틴
LCS/NACL/LRN. NACL 2군 및 세미프로 창단 가능.
LRN 라틴 세미프로 창단 가능.
프랜차이즈 탈락 공석이 있을 때 사무국 승인으로 승격. LCS 기준 8팀.

### 아시아태평양
LCP/LJL/PCS/VCS/FLS.
2군 제외 세미프로 PO 승자가 LCP 최하위와 승강전. LCP 1팀 탈락.

### 브라질/남미
CBLOL/CD/LRS. 하부리그 대표별 PO 및 CBLOL 최하위와 승강전, 1팀 탈락.

### 유럽
LEC 및 전체 하부리그 창단.
EMEA 우승/준우승 팀 LEC WINTER 초청.
우승/지속적인 호성적에 따른 사무국 공식 팀 승인과 기존 팀의 비공식 2부 강등.
실제 ERL 구성은 출처와 시즌 기준일을 확인해 구성.

## 현재 상태

- Python 버전의 경기 로직과 구단 기능 일부가 존재한다.
- C++ 이전판은 SUITE UI, 저장/주차/DB와 메뉴 전환을 작업 중이다.
- C++ 경기 엔진, 실제 경기 일정/순위/승강전, 계약/재정/관계/의료/훈련 효과,
  전체 챔피언 고유 스킬, 온라인 권한/투표/서버, 웹/APK는 완료되지 않았다.
- 실존 GCD 1,072명은 수집되었으나 역할 미분류/하부리그 누락이 있으며
  모든 선수/스탭/2026 폼이 검증된 완전 명단이 아니다.
- 단순 등록 명단을 1군/2군 전체 로스터로 단정하지 않는다.
- 선수 프로필 임시 50 수치는 실측 평가가 아니다.
