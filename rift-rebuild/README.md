# RIFT MANAGER — 새 매치엔진

`실행.cmd` 또는 `dist/RiftManager-Rebuild.exe`로 실행합니다.
기존 상위 프로젝트와 이전 게임 소스를 사용하거나 수정하지 않은 별도 구현입니다.

## 이번 버전의 기준

- 맵: 실제 Riot/CommunityDragon 리프트 PNG와 동일한 알파 영역에서 이동 가능 격자를 생성합니다.
  연결되지 않은 장식 영역은 제외하고 몸체 여유 공간을 확보합니다. 벽 모서리를 대각선으로
  뚫지 않으며 일반 이동·몬스터 추격·밀쳐내기는 경로 전체를 충돌 검사합니다.
- 도약/순간이동은 지정된 스킬에서만 명시적으로 처리하고 착지점도 이동 가능 영역에 제한합니다.
  일반 보행과 구분되는 순간이동 이펙트를 사용합니다.
- 기본 공격은 발사 시점의 **사거리와 지형 시야**를 모두 통과해야 합니다. 탄도가 이미 발사된 뒤
  대상이 이동하는 것은 허용합니다. 공격 감사 기록에는 실제 발사 거리와 허용 사거리가 남습니다.
- 정글 몬스터는 지도 픽셀 기준 공격 사거리 12, 보스 16을 사용합니다. 챔피언과 비교해 짧습니다.
  사거리 밖에서는 먼저 걸어와야 하며 캠프 원점에서 과하게 멀어지면 복귀·회복합니다.
- 캠프 무리의 모든 몬스터가 죽은 시점부터 재생성 타이머를 시작합니다. 유충 목표는 남은 개체가
  있는 동안 유지합니다. 유충은 개체별 실제 처치 팀에 귀속하므로 3:0 또는 2:1 분배가 가능합니다.
  특정 팀이 반드시 먹거나 반드시 분배하도록 결과를 조작하지 않습니다.
- 아이템은 포지션 공통 빌드 대신 17명 각각의 빌드를 사용합니다. 누누/사이온은 탱커,
  소라카는 지원, 마법사는 주문력, 원딜은 공격력 계열로 구분합니다.
- 귀환·부활 후 우물에서 체력과 마나를 완전히 채운 뒤 출발합니다.

## 관전

- 독립 Windows/SDL 화면, 60Hz 렌더 루프, 경기 계산은 별도 프로세스.
- 작은 챔피언 아이콘, 실제 아이템·용·바론·유충 아이콘, 상단 팀 정보와 왼쪽 오브젝트 패널.
- 정글 재생성 시간은 맵에 쓰지 않습니다. 오브젝트 상태만 왼쪽 패널에서 표시합니다.
- 폰트는 **갈무리11 Regular와 Bold**를 파일로 포함합니다. 사용자 컴퓨터 설치는 필요 없습니다.
- 표 위에 고정 FM식 자막. 하단 아이템 / 골드 / 한타 딜량은 하나씩만 표시합니다.
- 첫 장면은 전체 맵, 하이라이트는 오는 킬의 당사자와 주변 합류 선수를 추적하여 확대합니다.
  장면 종류를 맵 왼쪽 위와 자막에 명시합니다.
- 하이라이트는 **항상 1배속**입니다. 초반 배치 구간만 빠르게 진행합니다.
  정속 재생을 우선하므로 한 세트 관전 시간이 10분을 넘을 수 있습니다.
- 킬(10초 전), 주요 오브젝트(12초 전), 포탑/억제기 파괴(8초 전), 넥서스 파괴(30초 전)를 선택합니다.
  탈출·점멸·임의 돌발행동은 하이라이트 사유가 아닙니다. 한타의 킬들과 이어지는 넥서스 공략은 합칩니다.
- 근접 공격의 궤적, 원거리 탄도의 꼬리, 마법 탄도, 피격 링과 피해 숫자로 공격 대상이 보이게 합니다.
- 보간은 일반 이동에만 적용하고 부활/순간이동은 맵을 가로질러 미끄러지지 않게 구분합니다.

Space: 일시정지 / 좌우: 이전·다음 장면 / Esc: 전체 맵·자동 카메라.
창 크기에 맞춰 한 화면을 축소·확대하며 스크롤하지 않습니다.

## 데이터와 실행

- 기본 10명: 잭스·누누·애니·애쉬·알리스타 vs 사이온·워윅·라이즈·시비르·소라카.
- 초기 17명 키트를 정의했고 `Match(roster=...)`로 역할에 맞는 다른 조합을 지정할 수 있습니다.
- 패시브·QWER·아이템은 자체 게임 규칙입니다. 실제 게임의 모든 세부 상호작용이 완성되었다는 뜻은
  아닙니다. 일부 키트는 단순화되어 있으며 모든 현대 LoL 아이템/룬/챔피언을 구현하지 않았습니다.
- 와드와 지형 시야, 라인 웨이브, 캠프 무리, 강타, 포탑 어그로, 억제기/슈퍼 미니언,
  넥서스 포탑, 체력·마나·경험치·레벨·골드를 경기 상태에서 계산합니다.
- 기본 경기는 시간 제한 없이 진행합니다. 넥서스 파괴 시에만 승리를 판정합니다.
- 선수 표기 예시는 `app.py`의 `PLAYER_NAMES`에서 수정합니다. 실제 대회 로스터 데이터는 사용하지 않습니다.
- 온라인/구단 경영/밴픽은 현재 작업 범위 밖입니다.

개발 실행: `python app.py` (pygame, Pillow 필요).
검사: `python -m unittest discover -v`.
전체 경기 생성: `python replay.py --seed 1`.
프레임버퍼/리플레이 감사: `python qa.py`.
Windows 빌드: `python build.py` (PyInstaller 필요).

경기 결과는 `runs/match-<seed>.json.gz`에 저장합니다. 실행 파일에는 첫 경기 기록을 함께 넣어
바로 관전할 수 있게 하고, 새 경기 버튼은 새 시드의 경기를 자체 엔진으로 계산합니다.
런타임 외부 다운로드나 계정 연결은 없습니다.
